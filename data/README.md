# Datos AG News

Los archivos originales de la cátedra se encuentran en `data/ag_news/`:

- `ag_news_train.csv`: 8.000 documentos para entrenamiento y validación.
- `ag_news_test.csv`: 2.000 documentos reservados para prueba final.

Ambos contienen `text` y `label`. El archivo `cargar_dataset_catedra.py` fue provisto por la cátedra y conserva sus rutas originales.
